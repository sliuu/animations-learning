Lesson D008 · 18 minutes

Text that arrives

Kinetic type is not a pile of letters with a delay. Split the sentence at the level of meaning, then decide whether the reader should see a window opening or words entering the room.

Skill: choose split granularity, reveal style, and stagger from the reading unit← Lesson D007

D007 made the reader the owner of a scroll timeline. Here the reader still owns attention, but the designer owns the order: what is the first thought, what follows it, and how much waiting is worth asking for? Text arrives well when the motion makes that order easier to feel. It fails when every character becomes a tiny appointment.

Say it out loud

Kinetic type — text whose movement is part of its meaning.
Split granularity — the unit you animate: phrase, line, word, or character.
Stagger — a deliberate delay between units.
Mask reveal — the words stay in place while a window uncovers them.
Fade-up — the words arrive from dimmer and lower, then settle.
Reading unit — the chunk the reader can understand in one glance.

Start with the split, not the keyframes. In the lab, keep an eye on the two counters: the hero word can carry a beat per character because it is the picture. A paragraph is a sentence; making it wait for every character turns reading into a queue.

Try this, in order
  1. Play lines + together. The paragraph keeps its reading shape.
  2. Choose characters + countable. The hero gains a pulse; the paragraph shows its tax in beats and milliseconds.
  3. Switch to mask. It reads as uncovering. Switch back to fade-up: it reads as arrival. That is a change in promise, not a skin.
  4. Try words + quick on a short headline, then on body copy. Keep the smallest unit that changes meaning, not the smallest unit the browser can animate.

A split is a hierarchy made in time

Lines are usually the right first experiment for body copy. They preserve the sentence's shape while giving the entrance a clear cadence. Words can work for a short headline or a list whose items are genuinely separate. Characters are a special effect: one hero word, a logo-like title, or a deliberate spelling-out moment. Character-splitting ordinary prose is almost always wrong because the eye has to reconstruct words while the animation keeps changing the target.

This is not a ban on letters. It is a question of ownership: what is the reader waiting for? If the answer is “the next idea,” split by line or word. If the answer is “this word forming,” split by character. A 35ms delay can feel like a quick beat; 80ms is countable. The more units you create, the more total time you spend even when each delay looks tiny.

If you have read the engineering track: 0003's stagger lab gives you the arithmetic. D003's hierarchy claim is the design test: the unit that moves first is the unit you have ranked first. No engineering-track lesson is required to use that test.

Mask or fade: uncovering or arriving?

A mask reveal changes the window in front of still type. It says, “this was here; now you can see it.” A fade-up changes the type's state. It says, “this is entering your attention.” Both can be beautiful. They are not interchangeable, and a comparison needs to be simultaneous or your memory will quietly pick a winner for you.

Use a mask when the spatial place is stable and the reveal itself is the story: a line being uncovered, a crop opening, a title emerging from behind a surface. Use fade-up when arrival is the story: a new section, a caption gaining focus, or a sequence where the words should feel newly present. If the type should not move, do not fake its movement just because a split-text preset offers one.

If you have read 0013: that lesson calls this the window- versus-content decision. D008 applies the same distinction to typography, where a few pixels of travel can change whether the reader experiences “uncovering” or “entering.”

Keep the reading intact

Runtime line splitting depends on font metrics and available width. Fonts load, windows resize, and a line that was one unit can become two. A robust implementation re-splits after those changes, preserves the original text for assistive technology, and keeps generated units out of the accessibility tree. If the effect is decorative, the sentence must remain a sentence when motion is removed.

There is also a practical CSS detail: character spans can break words if they are allowed to wrap independently. Keep characters inside word-sized wrappers, or the demo teaches a broken line break instead of kinetic type. The lab does this deliberately so you can resize it without losing the thing being taught.

The CSS behind it

Show the mechanism
/* Split only as finely as the idea changes. */
.line { overflow: hidden; }
.line > span { display: block; }
.unit { display: inline-block; }

.is-playing .unit {
  animation: arrive 520ms var(--ease-out-strong) both;
  animation-delay: calc(var(--i) * var(--step));
}

@keyframes arrive {
  from { opacity: 0; transform: translateY(14px); }
  to   { opacity: 1; transform: none; }
}

@keyframes uncover {
  from { clip-path: inset(0 0 100% 0); }
  to   { clip-path: inset(0); }
}

Check yourself

You are animating a six-line paragraph. Which split is the strongest starting point?

Lines preserve the paragraph's shape and let the reader receive one visual thought at a time. Finer splits spend attention without adding meaning.

When is character splitting most defensible?

A single hero word can make each letter part of the visual event. Ordinary prose needs words to remain easy to recognize.

What does a mask reveal promise?

A mask changes visibility, not the type's position. That reads as uncovering. Fade-up changes the content's state and reads as arrival.

What should a responsive split-text implementation do when the font or width changes?

Line boundaries depend on measured font metrics. Re-split after relevant changes, keep an accessible original sentence, and preserve word wrapping.

Ask yourself: what is the smallest unit of meaning in the real page you want to animate? Bring one headline and one paragraph next time; we can choose their splits before choosing a library.
